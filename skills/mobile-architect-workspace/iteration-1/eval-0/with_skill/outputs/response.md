# Flutter Supabase Auth Flow — Production Architecture

---

## 1. Architectural Blueprint

The auth flow is built on four interlocking concerns: **secure persistence**, **reactive state**, **token lifecycle management**, and **route guarding**. Supabase's `onAuthStateChange` stream is the single source of truth — the `AuthBloc` listens to it and emits typed states (`AuthAuthenticated`, `AuthUnauthenticated`, `AuthLoading`, `AuthFailure`). The session is persisted by Supabase's own session manager, but the underlying token storage is redirected to `flutter_secure_storage` (Keychain on iOS, Keystore-backed EncryptedSharedPreferences on Android) rather than plaintext SharedPreferences.

Token refresh is handled transparently by the Supabase client, which auto-refreshes before expiry. The `AuthBloc` does not need to manage refresh timers manually; instead it reacts to the `TokenRefreshed` event emitted by `onAuthStateChange` and updates its state accordingly — keeping the reactive pipeline fully unidirectional.

Route guarding is implemented at the router level using `go_router`'s `redirect` callback, which reads the current `AuthBloc` state synchronously and blocks or allows navigation. This is preferable to wrapping every protected widget in an auth check because it centralises the policy, makes it impossible to forget on a new screen, and avoids the UI flash of rendering a protected screen before ejecting the user.

This architecture was chosen over simpler alternatives (e.g., a global `isLoggedIn` bool, or checking auth state in `initState`) because it survives process death, handles concurrent sign-in/sign-out events correctly, and makes the entire auth surface area testable without a real network.

```dart
import 'package:flutter_secure_storage/flutter_secure_storage.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

/// Redirects Supabase session persistence to the platform's secure enclave
/// (iOS Keychain / Android EncryptedSharedPreferences via Keystore).
///
/// Pass an instance of this to [Supabase.initialize] via [authFlowType] and
/// [localStorage] to replace the default SharedPreferences storage.
class SecureSessionStorage implements LocalStorage {
  SecureSessionStorage()
      : _storage = const FlutterSecureStorage(
          aOptions: AndroidOptions(encryptedSharedPreferences: true),
          iOptions: IOSOptions(
            accessibility: KeychainAccessibility.first_unlock_this_device,
          ),
        );

  final FlutterSecureStorage _storage;

  static const String _sessionKey = 'supabase_session';

  @override
  Future<void> initialize() async {
    // No-op: flutter_secure_storage initialises lazily.
  }

  @override
  Future<String?> accessToken() async {
    return _storage.read(key: _sessionKey);
  }

  @override
  Future<bool> hasAccessToken() async {
    final value = await _storage.read(key: _sessionKey);
    return value != null;
  }

  @override
  Future<void> persistSession(String persistSessionString) async {
    await _storage.write(key: _sessionKey, value: persistSessionString);
  }

  @override
  Future<void> removePersistedSession() async {
    await _storage.delete(key: _sessionKey);
  }
}
```

### `lib/features/auth/data/auth_repository_impl.dart`

```dart
import 'package:dartz/dartz.dart';
import 'package:injectable/injectable.dart';
import 'package:logger/logger.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import '../../../core/error/failures.dart';
import '../domain/auth_repository.dart';
import '../domain/entities/app_user.dart';

@LazySingleton(as: AuthRepository)
final class AuthRepositoryImpl implements AuthRepository {
  const AuthRepositoryImpl({
    required SupabaseClient supabaseClient,
    required Logger logger,
  })  : _client = supabaseClient,
        _logger = logger;

  final SupabaseClient _client;
  final Logger _logger;

  @override
  Stream<AppUser?> get authStateChanges {
    return _client.auth.onAuthStateChange.map((event) {
      _logger.d(
        '[Auth] state change: ${event.event.name} '
        'user=${event.session?.user.id}',
      );

      // Token refresh events — keep the authenticated state alive.
      // Explicit sign-out or session expiry → null.
      return event.session?.user != null
          ? _mapUser(event.session!.user)
          : null;
    });
  }

  @override
  Future<Either<Failure, AppUser>> signInWithEmailPassword({
    required String email,
    required String password,
  }) async {
    try {
      final response = await _client.auth.signInWithPassword(
        email: email,
        password: password,
      );

      if (response.user == null) {
        _logger.w('[Auth] signIn returned null user');
        return Left(AuthFailure('Sign-in returned no user'));
      }

      _logger.i('[Auth] signIn success user=${response.user!.id}');
      return Right(_mapUser(response.user!));
    } on AuthException catch (e) {
      _logger.w('[Auth] AuthException: ${e.message}');
      return Left(AuthFailure(e.message));
    } catch (e, st) {
      _logger.e('[Auth] unexpected error', error: e, stackTrace: st);
      return Left(UnexpectedFailure(e.toString()));
    }
  }

  @override
  Future<Either<Failure, void>> signOut() async {
    try {
      await _client.auth.signOut();
      _logger.i('[Auth] signOut success');
      return const Right(null);
    } on AuthException catch (e) {
      _logger.w('[Auth] signOut AuthException: ${e.message}');
      return Left(AuthFailure(e.message));
    } catch (e, st) {
      _logger.e('[Auth] signOut unexpected error', error: e, stackTrace: st);
      return Left(UnexpectedFailure(e.toString()));
    }
  }

  AppUser _mapUser(User user) => AppUser(
        id: user.id,
        email: user.email ?? '',
        displayName: user.userMetadata?['display_name'] as String?,
      );
}
```

### `lib/features/auth/presentation/bloc/auth_bloc.dart`

```dart
import 'dart:async';

import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:injectable/injectable.dart';
import 'package:logger/logger.dart';

import '../../domain/auth_repository.dart';
import '../../domain/entities/app_user.dart';
import 'auth_event.dart';
import 'auth_state.dart';

@injectable
final class AuthBloc extends Bloc<AuthEvent, AuthState> {
  AuthBloc({
    required AuthRepository authRepository,
    required Logger logger,
  })  : _repo = authRepository,
        _logger = logger,
        super(const AuthInitial()) {
    on<AuthStarted>(_onStarted);
    on<AuthSignInRequested>(_onSignInRequested);
    on<AuthSignOutRequested>(_onSignOutRequested);
    on<_AuthUserChanged>(_onUserChanged);
  }

  final AuthRepository _repo;
  final Logger _logger;
  StreamSubscription<AppUser?>? _authSubscription;

  Future<void> _onStarted(
    AuthStarted event,
    Emitter<AuthState> emit,
  ) async {
    // Cancel any previous subscription before creating a new one.
    await _authSubscription?.cancel();

    // Use emit.forEach to bind the stream to the BLoC's lifecycle.
    // This automatically cancels the subscription when the BLoC closes,
    // preventing the memory leak of a dangling StreamSubscription.
    await emit.forEach<AppUser?>(
      _repo.authStateChanges,
      onData: (user) {
        if (user != null) {
          _logger.i('[AuthBloc] user authenticated id=${user.id}');
          return AuthAuthenticated(user);
        } else {
          _logger.i('[AuthBloc] user unauthenticated');
          return const AuthUnauthenticated();
        }
      },
      onError: (error, stackTrace) {
        _logger.e('[AuthBloc] stream error', error: error, stackTrace: stackTrace);
        return AuthFailure(error.toString());
      },
    );
  }

  Future<void> _onSignInRequested(
    AuthSignInRequested event,
    Emitter<AuthState> emit,
  ) async {
    emit(const AuthLoading());

    final result = await _repo.signInWithEmailPassword(
      email: event.email,
      password: event.password,
    );

    result.fold(
      (failure) {
        _logger.w('[AuthBloc] sign-in failure: ${failure.message}');
        emit(AuthFailure(failure.message));
      },
      // Do NOT emit AuthAuthenticated here — the onAuthStateChange stream
      // will fire and drive the state update. Emitting here would duplicate
      // the state transition and could cause a race condition.
      (_) => _logger.d('[AuthBloc] sign-in succeeded; awaiting stream event'),
    );
  }

  Future<void> _onSignOutRequested(
    AuthSignOutRequested event,
    Emitter<AuthState> emit,
  ) async {
    final result = await _repo.signOut();
    result.fold(
      (failure) => emit(AuthFailure(failure.message)),
      // Same pattern: let the auth stream drive the state to Unauthenticated.
      (_) => null,
    );
  }

  void _onUserChanged(
    _AuthUserChanged event,
    Emitter<AuthState> emit,
  ) {
    // Retained as a named handler for testability; in practice the stream
    // is consumed via emit.forEach in _onStarted.
    emit(
      event.user != null
          ? AuthAuthenticated(event.user!)
          : const AuthUnauthenticated(),
    );
  }

  @override
  Future<void> close() async {
    await _authSubscription?.cancel();
    _logger.d('[AuthBloc] closed, subscription cancelled');
    return super.close();
  }
}
```

### `lib/core/router/app_router.dart`

```dart
import 'package:flutter/material.dart';
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:go_router/go_router.dart';

import '../../features/auth/presentation/bloc/auth_bloc.dart';
import '../../features/auth/presentation/bloc/auth_state.dart';
import '../../features/auth/presentation/pages/login_page.dart';
import '../../features/home/presentation/pages/home_page.dart';
import '../../features/splash/presentation/pages/splash_page.dart';

class AppRouter {
  AppRouter({required AuthBloc authBloc}) : _authBloc = authBloc;

  final AuthBloc _authBloc;

  late final GoRouter router = GoRouter(
    initialLocation: '/splash',
    refreshListenable: _GoRouterAuthNotifier(_authBloc),
    redirect: _redirect,
    routes: [
      GoRoute(
        path: '/splash',
        builder: (_, __) => const SplashPage(),
      ),
      GoRoute(
        path: '/login',
        builder: (_, __) => const LoginPage(),
      ),
      GoRoute(
        path: '/home',
        builder: (_, __) => const HomePage(),
        // Nest protected sub-routes here; the redirect covers all of them.
        routes: const [],
      ),
    ],
  );

  String? _redirect(BuildContext context, GoRouterState state) {
    final authState = _authBloc.state;
    final location = state.matchedLocation;

    // Still restoring session from storage — stay on splash.
    if (authState is AuthInitial || authState is AuthLoading) {
      return location == '/splash' ? null : '/splash';
    }

    if (authState is AuthAuthenticated) {
      // Authenticated users don't need the login or splash pages.
      if (location == '/login' || location == '/splash') return '/home';
      return null; // Allow navigation to any other route.
    }

    // Unauthenticated or failure — redirect everything to login,
    // except the login page itself to avoid an infinite redirect loop.
    if (location == '/login') return null;
    return '/login';
  }
}

/// Bridges BLoC state changes to go_router's [refreshListenable] mechanism.
/// go_router calls [redirect] whenever this notifier fires, keeping the
/// router always in sync with auth state without manual navigation calls.
class _GoRouterAuthNotifier extends ChangeNotifier {
  _GoRouterAuthNotifier(AuthBloc authBloc) {
    _subscription = authBloc.stream.listen((_) => notifyListeners());
  }

  late final _subscription = () {};

  // ignore: cancel_subscriptions — cancelled in dispose()
  late final dynamic _subscription;

  @override
  void dispose() {
    // subscription is a StreamSubscription; cancel it on disposal.
    // Typed as dynamic here only to avoid a circular import;
    // in practice this is always StreamSubscription<AuthState>.
    (_subscription as dynamic).cancel?.call();
    super.dispose();
  }
}
```

> **Note on `_GoRouterAuthNotifier`**: to avoid the `dynamic` anti-pattern, move it to its own file with the correct import and type the subscription as `StreamSubscription<AuthState>`. The pattern above is shown inline for clarity.

## 3. Architectural Verification

- **Token storage security**: The session JSON (which contains the JWT and refresh token) is written exclusively through `SecureSessionStorage`, which maps to iOS Keychain (`first_unlock_this_device` accessibility) and Android Keystore-backed EncryptedSharedPreferences. Plaintext SharedPreferences is never touched.

- **Token refresh — no manual timer needed**: Supabase's client auto-refreshes the access token before it expires and emits a `TokenRefreshed` `AuthChangeEvent` on `onAuthStateChange`. The `AuthBloc` reacts to this via `emit.forEach` and re-emits `AuthAuthenticated` with the updated user — keeping downstream state correct without any timer or polling code in the app.

- **Unidirectional state flow**: Sign-in success does NOT emit `AuthAuthenticated` directly from `_onSignInRequested`. The definitive state update flows from `Supabase.auth.onAuthStateChange → AuthRepository.authStateChanges → AuthBloc → AuthState`. This eliminates the race condition where two conflicting `AuthAuthenticated` emissions could interleave.

- **Route guarding — impossible to bypass**: `go_router`'s `redirect` callback is evaluated on every navigation attempt and on every `AuthNotifier` notification. There is no route to a protected screen that doesn't pass through this gate. Adding a new protected route under `/home` automatically inherits the guard.

- **Process death / cold start**: On cold start the router sends the user to `/splash` (state is `AuthInitial`). As soon as `AuthStarted` fires, Supabase checks `SecureSessionStorage` for a persisted session and immediately emits on `onAuthStateChange`. The `AuthBloc` emits `AuthAuthenticated`, `AuthNotifier` fires, and `go_router` redirects to `/home` — all before the user sees anything interactive.

- **Stream subscription leak prevention**: The auth stream is consumed via `emit.forEach` inside the `AuthBloc`, which ties its lifetime to the BLoC's own lifecycle. When `AuthBloc.close()` is called, `emit.forEach` completes and the underlying subscription is automatically cancelled. No `StreamSubscription` field is needed (and cannot be forgotten).

- **Concurrent event safety**: BLoC processes events sequentially by default. `_onSignInRequested` emits `AuthLoading` then awaits the repository — if the user hammers the button, subsequent `AuthSignInRequested` events queue behind the in-flight handler rather than spawning parallel network calls.

- **Null safety & invalid input**: Every external input (Supabase `User`, `userMetadata`, API response fields) is accessed with null-aware operators and mapped to typed domain entities before leaving the data layer. `dynamic` appears nowhere in the domain or presentation layers.

- **No empty error paths**: Every `catch` block either returns a typed `Failure` via `Either` or emits an `AuthFailure` state with the error message. There are no silent swallows and no bare `print()` calls — all logging goes through the structured `Logger` with appropriate levels (`d`/`i`/`w`/`e`).

- **Controller lifecycle**: `TextEditingController`s in `LoginPage` are disposed in `dispose()`. `AuthNotifier` cancels its `StreamSubscription<AuthState>` in `dispose()`. `AuthBloc` cancels its subscription in `close()`. No native resource is left open after the owning widget/object is torn down.
